# Release screenshots

Store only audited final assets, grouped as `${locale}/${displayFamily}/${order}-${state}.png`, plus the generated manifest. Raw captures stay in the release-specific temporary workspace.

The display families are resolved from the current official requirements cache. They are separate from the normal iPhone Pro/iPad Air verification matrix and may require an iPhone Pro Max. Never stretch captures, include personal/debug content, or reuse an image across locales when visible copy differs.
