# XPosts

このフォルダは、Xへ投稿する材料です。Claudeが機能を作るついでに残し（D-096）、Grok Botが読んで投稿します。

## Grok Botの立ち回りの案内

1. 読む場所：GitHubのこのリポジトリの`main`の`XPosts/`。mergeされた材料だけが投稿の対象で、ほかのブランチやPRの中は読まない。
2. フォルダ1つが投稿1つ分。フォルダ名の日付は材料を作った日で、投稿の順番の目安にしてよい（古いものから）。
3. `post.md`の「事実」に書いてあることだけを、機能の説明として使う。「推しどころ」は文面を考える材料で、そのまま使っても、言い換えてもよい。書いていない機能を足さない。
4. `post.json`の`media`に、画像と動画ごとの説明がある。Xの添付の上限（画像は4枚まで、または動画1本）に合わせて、推しどころが伝わるものを選ぶ。
5. `post.json`の`related`に書いてあるフォルダは、内容が近い。続けて投稿しない。
6. リポジトリの中のファイルを書き換えたり、消したり、commitしたりしない。投稿済みの記録は、Grok Bot自身の側に残す。
7. 投稿は1日1つ程度。
